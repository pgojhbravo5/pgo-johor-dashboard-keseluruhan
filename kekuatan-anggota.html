Apa itu Export Data?

Export Data ialah proses memuat turun salinan penuh data balai anda sebagai fail JSON ke komputer/peranti anda. Fail ini boleh digunakan sebagai backup, rujukan peribadi, atau untuk import semula ke dalam sistem.

Yang Akan Dieksport:

  • Identiti Balai — Nama balai dan kategori balai
  • Data Personel — Semua butiran anggota (nama, pangkat, no badan, telefon, peranan, pasukan, unit, catatan)
  • Data Jentera & Kenderaan — Jentera Utama, Marin, Utiliti & Komunikasi (maklumat, kategori, catatan)

Maklumat Export:

Balai: —
Format Fail: JSON (.json)
ℹ Nota: Fail export tidak menjejaskan data di Supabase. Ia hanya salinan setempat untuk rujukan/backup anda.
⚠ Penting: Kolum STATUS tidak disertakan dalam fail export — jika fail ini di-import semula ke sistem, semua STATUS akan menjadi kosong dan perlu diisi manual.
